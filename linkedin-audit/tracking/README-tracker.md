# Weekly Tracker: how to use it

- Fill in **row 0 (Baseline)** on Day 1, then one row every Sunday.
- Where to find the numbers: your profile → Analytics (profile views, search appearances, post impressions); My Network (connections, sent invitations); each post's analytics (impressions, comments).
- `Acceptance_Rate_%` = Requests_Accepted ÷ Connection_Requests_Sent × 100.
- `Meaningful_Conversations` = DM threads with 3+ back-and-forth replies on a professional topic.
- `Business_Leads_Qualified` = a brand-side person who has said they'd consider working with a sourcing partner like you.

**Power Query practice:** load this CSV into Excel (Data → From Text/CSV). Add a custom column for acceptance rate, and build a line chart of Profile Views and Followers by week. That's a mini-dashboard you can turn into a post (week 8 or 12).
